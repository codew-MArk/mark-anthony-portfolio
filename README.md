# Mark Anthony Bundoc | Portfolio

Welcome to my personal portfolio, a showcase of my work as a software engineer who enjoys building interactive web applications with smooth animations and clean user experiences. The site is built with Next.js, React, TypeScript, and Tailwind CSS, and features a dark, gradient-styled design. It includes a Projects section with live demos and source code for my work, such as NEXORA, an e-commerce storefront, and SketchRoom, a real-time collaborative drawing board. 

**Live site:** https://mark-anthony-port-sample.vercel.app
